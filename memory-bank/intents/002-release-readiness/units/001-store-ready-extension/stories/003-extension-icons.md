# Story: 003-extension-icons

## User Story

**As a** Chrome user
**I want** a recognisable cv-snap icon in the toolbar and the store
**So that** I find the extension and the store accepts it

## Acceptance Criteria

- [ ] **Given** the manifest, **When** built, **Then** `icons` and `action.default_icon` list 16, 32, 48 and 128 px PNGs
- [ ] **Given** a 16 px toolbar on light and dark themes, **When** shown, **Then** the mark stays recognisable
- [ ] **Given** the 128 px icon, **When** checked, **Then** the artwork is 96×96 with 16 px transparent padding (CWS guideline)

## Technical Notes

- One SVG source in the repo; PNGs generated by a script (committed), so builds need no image tooling

## Edge Cases

| Scenario | Expected Behavior |
|---|---|
| Badge text on the icon (job ad detected) | Still readable over the new icon |
